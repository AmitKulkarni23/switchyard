# 10 Persistence and share links

Postgres via Drizzle (`drizzle-orm/bun-sql`). Table `estimates` (id short random slug, created_at, workload jsonb). Never the raw bill. `POST /api/estimates` stores the workload and returns `id`; `GET /api/estimates/:id` returns the workload. Migrations generated by drizzle-kit and run at startup. Without `DATABASE_URL`, share links are disabled with a clear log.

**Acceptance**: migration applies; round-trip test against a database when `DATABASE_URL` is set (skipped otherwise).
